# 口令卡 · 小鲸排 Skill

复制下面任意一句发给我，我就能跑完整条链路。

> **不用打任何英文。** 下面所有口令都是中文，够用了。
> `xiaojingpai` 这类是**我用的内部 skill 名**（用来找文件、定位脚本），**你从头到尾都不需要打出来**。
> 中文里只要出现「AGI绿 / 排版 / 配图 / 标重点 / 草稿箱」这几个词，我就知道该干什么。

## 先看一眼它怎么干活

![小鲸排 Skill 三步流程图](assets/flow-3-steps.png)

一句中文口令进来 → ① 排版 ② 配图 + 标重点 ③ 写进草稿箱。中间的活儿我全包，你只要说清楚要什么。

---


## 一、标准口令（最常用）

```
用 AGI绿 排版这篇，配图 + 重点标粗下划线，推到草稿箱：

<腾讯文档链接>
```

把 `<腾讯文档链接>` 换成 `https://docs.qq.com/doc/XXXX` 即可。腾讯文档也可以直接用 `@tdoc#<file_id>` 引用。

## 二、什么都不想写时（最省事）

```
排这篇推草稿箱：<链接>
```

我会走默认：**AGI绿** + 自动判断重点 + 有合适的官方配图就配 + 推草稿箱。

## 三、换主题

把「AGI绿」替换成：

| 写这个 | 主题 | 适合 |
|---|---|---|
| AGI绿 | 栈式 48px 大绿编号 + 可选英文标签 | **默认**。新闻解读、行业观察、叙事长文 |
| 字节绿 | 渐变绿签 + 渐变标题 | 工具实测、教程、功能清单 |
| 杂志绿 | 杂志封面 + 导读卡 | 测评、快讯、工具盘点 |
| Pro蓝 | 蓝色数字徽章 + 居中斜体 | 商业观察、专业长文 |

例：`用杂志绿排版这篇推到草稿箱：<链接>`

## 四、只要预览，不要推

```
用 AGI绿 排版这篇，先出本地预览别推草稿：<链接>
```

## 五、改已存在的草稿

```
把这版更新到草稿 <media_id>：<链接>
```

⚠️ 后台若被手工改过，我会**拒绝覆盖**并先问你。要么你确认「覆盖掉」，要么我新建一条草稿保留两边。

## 六、不要配图 / 不要标重点

在口令里加一句就行：

- `不要配图`
- `不要自动标重点，只排版`
- `重点只加粗，不要下划线`

---

## 七、口语怎么说都认（关键的一节）

不必背句式，**认关键词**就行：

| 你想干什么 | 说这些词我都认 |
|---|---|
| 选主题 | `AGI绿`、`字节绿`、`杂志绿`、`Pro蓝`（不说就默认 AGI绿） |
| 排版 | `排版`、`排一下`、`排成公众号`、`转成推文` |
| 配图 | `配图`、`插图`、`加几张图`、`找官方图` |
| 标重点 | `标重点`、`重点标粗`、`加下划线`、`你看着标` |
| 推送 | `推草稿箱`、`推到后台`、`推公众号`、`一键发布` |
| 不推送 | `只出预览`、`先别推`、`本地看看` |

三个等价的说法，随便挑一个：

```
① 排这篇推草稿箱：<链接>
② 用AGI绿配图，重点标粗加下划线，推到鲸选AI草稿箱：<链接>
③ AGI绿，配图，标重点，推草稿：<链接>
```

## 文档里为什么会出现英文 skill 名（可跳过）

- 小鲸排 Skill 的英文名是 `xiaojingpai`（拼音），拆成三个：`xiaojingpai`（总控）/ `xiaojingpai-render`（排版）/ `xiaojingpai-push`（推送）。
- 这三个名字是给工具找目录用的，必须存在，但我调用时自己会找，不靠你打。
- 只有**换电脑安装、排查故障**那类文档需要对着目录名操作（见 `new-machine-setup.md`），日常发文一律用中文口令。
- 旧版口令曾把内部英文名一起写进去（「用 jingxuan-ai-gzh 的 AGI绿 排版这篇……」），那是误抄，已改掉。

## 我会在后台做的事（你可以不看）

1. 读腾讯文档原文（含 docx 级加粗信息，不靠猜）
2. 转成 `article.json`（文字零改动）
3. 按主题渲染 HTML，跑合规校验
4. 抓官方配图 → 上传微信素材 → 写进正文
5. 打重点（整句 `strong` 加粗 / 关键词 `underline` 下划线）
6. 生成主题色封面
7. `draft/add` 或 `draft/update` 写入草稿箱
8. `draft/get` 回读，确认微信没吞样式
