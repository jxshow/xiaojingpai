# 口令卡 · 鲸选AI 公众号发布

复制下面任意一句发给我（钉钉/微信/任何地方都行，只要在这台电脑的 WorkBuddy 里），我就能跑完整条链路。

---

## 一、标准口令（最常用）

```
用 jingxuan-ai-gzh 的 AGI绿 排版这篇，配图 + 重点标粗下划线，然后推到鲸选AI 草稿箱：

<腾讯文档链接>
```

把 `<腾讯文档链接>` 换成 `https://docs.qq.com/doc/XXXX` 即可。腾讯文档也能直接用 `@tdoc#<file_id>` 引用。

## 二、什么都不想写时（最省事）

```
把这篇排好推到草稿箱：<链接>
```

我会走默认：**AGI绿** + 自动判断重点 + 有合适的官方配图就配 + 推草稿箱。

## 三、换主题

把「AGI绿」替换成：

| 写这个 | 主题 | 适合 |
|---|---|---|
| AGI绿 / agi-green | 栈式 48px 大绿编号 + 可选英文标签 | **默认**。新闻解读、行业观察、叙事长文 |
| 字节绿 / byte-green | 渐变绿签 + 渐变标题 | 工具实测、教程、功能清单 |
| 杂志绿 / magazine-green | 杂志封面 + 导读卡 | 测评、快讯、工具盘点 |
| Pro蓝 / pro-blue | 蓝色数字徽章 + 居中斜体 | 商业观察、专业长文 |

例：`用杂志绿排版这篇推到草稿箱：<链接>`

## 四、只要预览，不要推

```
用 AGI绿 排版这篇，先出本地预览别推草稿：<链接>
```

## 五、改已存在的草稿

```
把这版更新到草稿 <media_id>：<链接>
```

⚠️ 后台若被手工改过，我会**拒绝覆盖**并先问你。要么你确认「覆盖掉」，要么我新建一条草稿保留两边。

## 六、不要配图 / 不要标重点

在口令里加一句就行：

- `不要配图`
- `不要自动标重点，只排版`
- `重点只加粗，不要下划线`

---

## 我会在后台做的事（你可以不看）

1. 读腾讯文档原文（含 docx 级加粗信息，不靠猜）
2. 转成 `article.json`（文字零改动）
3. 按主题渲染 HTML，跑合规校验
4. 抓官方配图 → 上传微信素材 → 写进正文
5. 打重点（整句 `strong` 加粗 / 关键词 `underline` 下划线）
6. 生成主题色封面
7. `draft/add` 或 `draft/update` 写入草稿箱
8. `draft/get` 回读，确认微信没吞样式
